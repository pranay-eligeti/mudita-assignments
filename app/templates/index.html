Assignment 1 · Sales assistant

Inquiry → qualification with evidence → routing → real Google Calendar booking, with human takeover and a full action log. Protected by HTTP basic auth (credentials are in the submission).

Assignment 2 · Three agents

Intake → Planning ⇄ Review with validated handoffs, run IDs, resume, fact correction with rerun, and labelled simulated faults. Each browser session is private.
